# Morphly homepage media

The public homepage uses approved, real Morphly media. The hero background is
provided by:

- `morphly-hero.mp4`

The remaining labelled asset slots can be filled by adding these optimized
files without changing the component code:

- `morphly-hero-poster.webp`
- `morphly-image-motion.mp4`
- `morphly-image-motion-poster.webp`
- `morphly-video-transform.mp4`
- `morphly-video-transform-poster.webp`
- `morphly-product-study.mp4`
- `morphly-product-study-poster.webp`
- `morphly-dashboard.webp`

Recommended delivery:

- MP4 video encoded for web playback, with audio removed unless it is essential.
- WebP posters using the same crop as the video.
- `morphly-dashboard.webp` captured from the current production creator screen.
- Keep each video short and optimized; do not add private user output without
  permission to publish it.
